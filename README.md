# Adidas Sales Dashboard 📊

## Project Overview

The **Adidas Sales Dashboard** is an interactive data visualization project created using **Power BI** to analyze Adidas sales performance across different regions, retailers, products, and sales methods.

* Total sales performance
* Operating profits and margins
* Regional sales distribution
* Product-wise unit sales
* Retailer contribution
* Monthly sales trends

---

## Dashboard Highlights

### Key KPIs

* **Total Units Sold:** 2M
* **Average Price Per Unit:** 45.22
* **Total Operating Profit:** 332.13M
* **Overall Sales:** 900M
* **Operating Margin:** 332M

---

## Features

* 📌 Interactive Power BI Dashboard
* 📈 Sales Trend Analysis by Year
* 🌍 Region-wise Sales Insights
* 🛍️ Product-wise Sales Comparison
* 🏬 Retailer Performance Tracking
* 💹 Operating Profit & Margin Analysis
* 📊 Donut Charts, Bar Charts, Line Charts & Treemap Visualizations

## Tools & Technologies Used

* **Power BI**

* **Data Cleaning & Transformation**

---

## Dashboard Insights

* West region generated the highest operating profit.
* Men's Street Footwear recorded the highest units sold.
* In-store sales method contributed the highest sales percentage.
* Sales peaked during August and September.

---

## How to Use

1. Download the `.pbix` file
2. Open using Power BI Desktop
3. Explore interactive filters and visualizations
